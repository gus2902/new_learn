# Moments: Mind Studio

## Product Brief

> **"당신의 지혜가 쌓이고, 당신의 영혼이 숨 쉬는 서재."**
> *Where your wisdom accumulates and your soul breathes.*

---

## 1. Executive Summary

**Moments: Mind Studio**는 정보 과잉 시대에 '나'를 잃어가는 현대인들을 위한 **지식 사진관**입니다. 단순한 웹 클리핑 도구를 넘어, 사용자가 저장한 정보들을 통해 자신의 관심사, 감정, 그리고 삶의 궤적을 되돌아볼 수 있는 **자아 회복 솔루션**입니다.

### 핵심 가치 제안
- **정보가 아닌 '나의 시선'을 저장합니다**: 클리핑은 단순 저장이 아니라, 그 순간 내 마음을 찍는 사진 행위입니다.
- **지식이 스스로 연결됩니다**: 사용자가 분류하지 않아도 AI가 맥락을 분석해 지식의 다리를 놓아줍니다.
- **일기를 통해 나를 되찾습니다**: 매일 밤, 오늘 모은 조각들을 돌아보며 '나'라는 존재를 기록합니다.

## 2. Problem Statement

### 현재 시장의 문제점

#### 2.1 기존 솔루션들의 한계
| 문제 | 설명 |
|------|------|
| **잊혀지는 클리핑** | 저장만 하고 다시 보지 않음. 정작 필요할 때 찾지 못함. |
| **파편화된 지식** | 여러 툴에 흩어진 정보들이 서로 연결되지 않음. |
| **불완전한 저장** | 링크 깨짐, 이미지 손실, 원본 URL만 저장되어 원본 소멸 시 접근 불가. |
| **중복 저장** | 이미 저장했는지 기억나지 않아 같은 자료를 반복 저장. |
| **의도의 망각** | '왜' 저장했는지, 어떤 맥락에서였는지 잊어버림. |
| **정리의 숙제화** | 폴더 분류, 태깅 등을 사용자에게 숙제로 남겨둠. |

#### 2.2 더 깊은 문제: 자아의 상실
> "현대인들은 수많은 정보 속에서 나를 자꾸 잃어가고 있어. 그렇게 많은 정보를 찾고 공부하고 힘든 삶을 살아가지만 정작 **나**라는 존재는 잊고, 내가 무얼 좋아하는지 싫어하는지조차 모르고 살아가고 있어."

## 5. Core Features

### 5.1 The Capture: 찰나의 기록

#### 5.1.1 Seamless Capture (끊김 없는 캡처)
- **Share Extension**: 모든 앱에서 '공유하기'로 즉시 클리핑
- **Browser Extension**: 웹 브라우저에서 원클릭 캡처
- **Clipboard Detection**: 복사한 링크 자동 감지 및 저장 제안

#### 5.1.2 Instant Snapshot (영구 박제)
- 원본 페이지의 HTML, 이미지, 텍스트를 완전 보존
- 원본 URL이 사라져도 사진관 내 데이터는 영구 접근 가능
- 광고/불필요한 요소 제거한 Clean View 자동 생성

#### 5.1.3 Mood Imprint (무드 각인)
- 클리핑 시 5가지 무드 컬러 중 하나 선택 (2초 내 완료)
- 키보드 없이 감정 상태 기록 가능
- 선택한 무드는 일기 작성 시 배경 색상으로 활용

#### 5.1.4 Smart Deduplication (지능형 중복 감지)
- 동일 URL 감지 시 "이미 사진관에 있어요" 알림
- 유사 콘텐츠 감지 시 "비슷한 자료가 N개 있습니다" 안내
- 반복 저장은 '열정의 신호'로 긍정적 해석

#### 5.1.5 Ghost Memo (한 줄 생각)
- 음성 메모 또는 AI 추천 키워드로 빠른 의도 기록
- 강제가 아닌 선택 사항 (마찰 최소화)

---

### 5.2 The Studio: 아침의 준비 (오전 9시 루틴)

#### 5.2.1 Today's Arsenal (오늘의 무기)
- 오늘 일정/프로젝트와 연관된 과거 클립 자동 큐레이션
- "오늘 기획 회의에 이 레퍼런스가 도움될 거예요" 형태의 제안

#### 5.2.2 Quick Menu (이동시간 전용)
- 3분 요약 카드로 미처 보지 못한 클립 소화
- Swipe 제스처로 "일기에 포함" / "나중에" 빠른 분류
- 지하철, 버스 등 이동 중 최적화된 UI

---

### 5.3 The Atelier: 밤의 일기 (오후 9시 루틴)

#### 5.3.1 Smart Curation & Hand Finishing
- **AI Draft**: 오늘 클립들을 테마별로 자동 배치한 초안 제공
- **Manual Touch**: 드래그 앤 드롭으로 조각 위치 조정
- **Knowledge Bridge**: "이 조각은 3개월 전 [A]와 연결되어 있어요" 자동 제안

#### 5.3.2 The Self-Query (나를 묻는 질문)
- 정보 나열이 아닌, 마스터님의 내면을 끄집어내는 질문
- "이 글을 저장할 때 어떤 기분이었나요?"
- "이 식당 정보를 저장하며 누구와 함께할 미래를 그리셨나요?"

#### 5.3.3 Identity Journal (나를 기억하는 일기)
- 외부 정보(Clip)와 내면 감정(Me)의 블렌딩
- 오늘 찍은 사진, 일상의 사소한 조각도 함께 기록
- 업무 일지가 아닌, '나'를 찾는 성찰의 시간

#### 5.3.4 Voice Journal (음성 일기)
- 글쓰기 힘든 날, 목소리로 하루를 기록
- 음성의 톤과 템포까지 감정 메타데이터로 저장

---

### 5.4 Emotional Search: 감성 검색

#### 5.4.1 Context Metadata
- **날씨/계절**: "비 오던 작년 여름에 저장한 글"
- **위치**: "강남역 카페에서 저장한 레퍼런스"
- **감정**: "열정에 불타던 시기의 자료들"
- **체류 시간**: "10분 넘게 꼼꼼히 읽으며 저장한 것들"

#### 5.4.2 The Memory Dial
- 키워드 검색창 대신 '기억의 다이얼' UI
- 시간, 감정, 장소를 조합해 지식 카드가 선명해지는 경험
- "검색"이 아닌 "재발견"의 경험

---

### 5.5 Shared Studio: 공동 사진관

#### 5.5.1 Themed Albums (테마형 공동 앨범)
- "제주도 여행 준비", "신혼집 인테리어" 등 목적별 보관함
- 소중한 사람 초대 → 각자 클리핑 → 한곳에서 취합

#### 5.5.2 Knowledge Gifting (지식의 선물)
- 내가 모은 소중한 조각을 예쁜 봉투에 담아 선물
- "이 글을 보는데 네 생각이 났어" 메시지와 함께 전송

#### 5.5.3 Silent Resonance (조용한 공명)
- 대화 없이도 상대방의 최근 관심사를 슬쩍 구경
- 정서적 연결의 깊이를 더함

### 6.3 Micro-copy Tone
- 숙제 강요 X, 따뜻한 초대 O

- "저장되었습니다" → "이 조각은 오늘 밤 사진관에서 현상해둘게요"

## 10. Technical Considerations (Updated 2026-01-08)

### 10.1 Core Engines & Research Insights

#### 10.1.1 Permanent Archive Engine
- **Strategy**: SingleFile CLI (MVP) → Playwright + Browsertrix (Scale).
- **Format**: **WACZ (Web Archive Collection Zipped)** 채택. HTTP Range Request를 통해 전체 파일을 다운로드하지 않고도 브라우저에서 즉시 재생 가능.
- **Infra**: K8s 기반 헤드리스 브라우저 클러스터 운영. 캡처당 비용 ~$0.01-0.05 수준 최적화.

#### 10.1.2 Semantic Graph Engine
- **Framework**: **LlamaIndex (PropertyGraphIndex)** + Neo4j.
- **Optimization**: **LazyGraphRAG** 패턴 도입. 초기 인덱싱 시 LLM 비용을 최소화하고, 쿼리 시점에 필요한 서브그래프만 동적 추출하여 운영 비용 70-90% 절감.
- **Retrieval**: Vector 유사도 + Graph 위상 구조 + Keyword를 결합한 하이브리드 검색.

#### 10.1.3 Emotional Search Engine
- **Modeling**: Plutchik 8대 감정 + VAD(Valence-Arousal-Dominance) 하이브리드 추출.
- **Privacy**: **Local LLM (Ollama)** 우선 처리. 민감한 일기 데이터의 감성 분석을 로컬에서 수행하여 데이터 주권 보장.
- **Standard**: JSON-LD 및 EmotionML 표준 준수, 시스템 간 상호 운용성 확보.

### 10.2 Implementation Roadmap

- **Q1-Q2 (Foundation)**: WACZ 캡처 엔진 구축, 기본 벡터 검색 및 모바일 Share Extension 개발.
- **Q3 (Intelligence)**: 감성 추출 파이프라인(Ollama/RoBERTa) 및 LlamaIndex 기반 지식 그래프 통합.
- **Q4 (Expansion)**: D3.js 기반 'Constellation View' 시각화, 커뮤니티 공유 기능 및 정식 런칭.

## 11. Market Strategy & Differentiation

### 11.1 Market Positioning
- **The Emotional Second Brain**: 기존 PKM(Obsidian, Notion)이 '지식의 양과 연결'에 집착할 때, Moments는 **'지식의 보존과 정서적 교감'**에 집중함.
- **Target**: 정보 과잉에 지친 지식 노동자(The Overwhelmed Strategist) 및 자기 성찰을 원하는 기록광(The Self-Reflecting Soul).

### 11.2 Competitive Edge
1. **영구 박제 (Immutable Archive)**: 링크가 깨져도 내 사진관 안의 지식은 영원히 보존.
2. **감성 검색 (Resonant Search)**: "비 오던 날의 우울했던 기억"과 닮은 지식을 찾아주는 독보적 경험.
3. **Product-Led Growth (PLG)**: 브라우저 익스텐션과 무료 캡처 기능을 통한 빠른 초기 선점.

### 11.3 Risk & Regulatory Compliance
- **EU AI Act 대응**: 감성 분석을 '감시'가 아닌 '정리 보조'로 정의. Local AI 모델 사용을 통해 규제 리스크 원천 차단.

## 10. Technical Considerations

### 10.1 Core Engines
- **Permanent Archive Engine**: HTML/이미지 완전 보존, 원본 독립적 접근
- **Semantic Graph Engine**: AI 기반 지식 연결 및 자동 분류
- **Emotional Metadata Engine**: 맥락(시간, 장소, 감정, 체류시간) 자동 수집
- **Smart Deduplication Engine**: URL + 콘텐츠 유사도 기반 중복 감지

### 10.2 Platform Strategy
- **Phase 1**: iOS/Android 앱 + Browser Extension
- **Phase 2**: Desktop 앱 + Web 버전
- **Phase 3**: API 개방 (3rd party 연동)
