### 결정 근거 (10가지 항목 기반)

1. **시장 블루오션:** Collector's Fallacy 미해결 (80% 사용자가 저장 후 다시 보지 않음)[1]
2. **기술 진입 장벽:** 낮음 (스크래핑 + AI 요약 성숙, MVP 2~3개월)
3. **사용자 채택 용이성:** 프리미엄 전환 + 바이럴 가능 (브라우저 확장, PKM 커뮤니티)
4. **B2B 확장:** Bottom-up 자연 확산 (개인 → 기업, 팀 공유 기능)
5. **비즈니스 모델 확장:** API 플랫폼화 (개발자 생태계, 노트 툴 플러그인, 콘텐츠 마켓플레이스)
6. **AI 기술 발전 대응:** RAG + Agent (의미적 검색, 자동 크롤링, 요약, 연결)
7. **한국 시장 특화:** 한국어 최적화 + 로컬 콘텐츠 스크래핑 (네이버, 다음, 브런치)
8. **트렌드 민첩성:** 빠른 기능 추가 (기술 복잡도 낮음, PKM 트렌드 반영)
9. **사용자 LTV:** 높은 잔존율 (매일 사용, 데이터 네트워크 효과, LTV 2~3년)
10. **시장 진입 속도:** 빠른 PMF (MVP 2~3개월, 초기 사용자 확보 용이)
