## 🎯 SAM 추정 방법론

### SAM 정의
**SAM (Serviceable Available Market):** 우리 제품/서비스가 실제로 도달 가능한 시장 규모

### 계산 방식
```
SAM = TAM × 접근 가능한 시장 비율
```

또는

```
SAM = 타겟 세그먼트별 시장 규모 합계
```

## 📊 세분화 기준 명확화

### 왜 이 세그먼트인가?

#### 1. 연구원/학생 (40%, 김지은)
- **이유 1:** 가격 민감도가 높지만, 무료 플랜으로 초기 사용자 확보 가능
- **이유 2:** 바이럴 마케팅 효과 (대학원생 커뮤니티)
- **이유 3:** 장기적 LTV (졸업 후에도 사용 지속)
- **전략:** 무료 플랜 제공 → 프리미엄 전환 유도

#### 2. 개발자/디자이너 (30%, 박민수)
- **이유 1:** 기술 활용도가 높아 빠른 채택 가능
- **이유 2:** API 통합으로 생태계 구축 가능
- **이유 3:** 개발자 커뮤니티에서 바이럴 효과
- **전략:** API 통합, 개발자 친화적 기능 제공

#### 3. 지식 근로자/기획자 (20%, 이수진)
- **이유 1:** 협업 필요도가 높아 팀 공유 기능으로 전환 비용 높임
- **이유 2:** B2B 확장의 첫 단계
- **이유 3:** Notion 등 협업 도구 통합으로 차별화
- **전략:** 팀 공유 기능, Notion 통합 강화

#### 4. 기업 R&D (10%, 최영호)
- **이유 1:** 가격 민감도가 낮아 높은 ARPU 가능
- **이유 2:** B2B 매출 확대
- **이유 3:** 기업 보안 정책 준수로 차별화
- **전략:** B2B 플랜, 온프레미스 옵션 제공

### 접근 가능성 평가

| **세그먼트** | **접근 가능성** | **이유** | **전략** |
| --- | --- | --- | --- |
| **연구원/학생** | 🟢 높음 | 무료 플랜, 바이럴 마케팅 | PKM 커뮤니티 공략 |
| **개발자/디자이너** | 🟢 높음 | 기술 활용도 높음, API 통합 | 개발자 커뮤니티 공략 |
| **지식 근로자/기획자** | 🟡 중간 | 협업 도구 통합 필요 | Notion 통합 강화 |
| **기업 R&D** | 🟡 중간 | B2B 기능 필요, 보안 정책 | B2B 플랜 개발 |

## 📋 가정 리스트

### 가정 1: 프리미엄 전환율
- **가정:** 페르소나별 프리미엄 전환율 (김지은 10%, 박민수 25%, 이수진 20%, 최영호 30%)
- **근거:** 경쟁사 분석 (Notion 15-20%, Readwise 20-25%), 페르소나별 가격 민감도
- **리스크:** 실제 전환율이 가정보다 낮을 경우 SAM 감소
- **완화 전략:** 무료 플랜 기능 제한, 프리미엄 가치 명확화, 학생 할인 제공

### 가정 2: 한국 시장 집중 전략
- **가정:** Phase 1에서 한국 시장 100% 집중
- **근거:** 한국어 최적화, 로컬 콘텐츠 지원, 초기 마케팅 비용 절감
- **리스크:** 한국 시장이 예상보다 작을 경우
- **완화 전략:** 글로벌 확장 준비 (Phase 2)

### 가정 3: 타겟 세그먼트 비중
- **가정:** 연구원/학생 40%, 개발자 30%, 지식 근로자 20%, 기업 R&D 10%
- **근거:** PHASE 1 분석, PHASE 3 페르소나 설계
- **리스크:** 실제 시장 비중이 다를 경우
- **완화 전략:** 시장 반응에 따라 세그먼트 비중 조정

### 가정 4: 페르소나별 ARPU
- **가정:** 김지은 $60/년, 박민수 $96/년, 이수진 $96/년, 최영호 $180/년
- **근거:** 경쟁사 ARPU 분석, 페르소나별 가격 민감도
- **리스크:** 실제 ARPU가 가정보다 낮을 경우
- **완화 전략:** 가격 전략 조정, 가치 제안 강화
