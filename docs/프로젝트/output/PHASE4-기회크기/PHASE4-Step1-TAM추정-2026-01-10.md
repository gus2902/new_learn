## 🎯 TAM 추정 방법론

### TAM 정의
**TAM (Total Addressable Market):** 우리 제품/서비스가 도달할 수 있는 전체 시장 규모

### 계산 방식
```
TAM = 전체 잠재 고객 수 × 평균 연간 지출 (ARPU)
```

또는

```
TAM = 전체 시장 규모 (PKM 시장 전체)
```

## 📊 TAM 추정: 방법 2 - 잠재 고객 수 × ARPU

### 전체 잠재 고객 수 계산

#### 세계 시장

| **데이터 소스** | **내용** | **데이터** | **출처** |
| --- | --- | --- | --- |
| **World Bank 2024** | 세계 인구 | 8.1B 명 | World Bank Data |
| **ILO 2024** | 지식 노동자 비율 | 30% (세계 평균) | ILO, "Global Employment Trends 2024" |
| **McKinsey 2023** | 디지털 도구 사용자 비율 | 60% (지식 노동자 중) | McKinsey, "Digital Transformation Report 2023" |
| **PHASE 1 분석** | PKM 도구 사용자 비율 | 20% (디지털 도구 사용자 중) | PHASE1-Step4-최종시장결정-2026-01-10.md |

**계산:**
```
세계 지식 노동자 수 = 8.1B × 30% = 2.43B 명
디지털 도구 사용자 = 2.43B × 60% = 1.458B 명
PKM 도구 잠재 사용자 = 1.458B × 20% = 291.6M 명
```

| **PHASE 1 분석** | PKM 도구 사용자 비율 | 25% (지식 노동자 중) | PHASE1-Step4-최종시장결정-2026-01-10.md |


### 평균 연간 지출 (ARPU) 계산

#### 경쟁사 ARPU 분석

| **경쟁사** | **가격 모델** | **월 ARPU** | **연 ARPU** | **출처** |
| --- | --- | --- | --- | --- |
| **Notion** | Personal: $8/mo, Team: $10/user/mo | $8-10 | $96-120 | Notion 공식 사이트 (2024) |
| **Obsidian** | Personal: 무료, Sync: $8/mo | $8 | $96 | Obsidian 공식 사이트 (2024) |
| **Readwise Reader** | Personal: $9.99/mo | $9.99 | $119.88 | Readwise 공식 사이트 (2024) |
| **Raindrop** | Pro: $3/mo, Pro+ $5/mo | $3-5 | $36-60 | Raindrop 공식 사이트 (2024) |
| **Evernote** | Personal: $8.99/mo | $8.99 | $107.88 | Evernote 공식 사이트 (2024) |

**평균 ARPU 계산:**
```
월 ARPU 평균 = ($8 + $8 + $9.99 + $4 + $8.99) / 5 = $7.80
연 ARPU 평균 = $7.80 × 12 = $93.60
```

**보수적 추정 (무료 플랜 고려):**
```
프리미엄 전환율 20% 가정
실제 ARPU = $93.60 × 20% = $18.72/년
```

**현실적 추정 (프리미엄 사용자 기준):**
```
프리미엄 사용자 연 ARPU = $93.60/년
```

## 📋 가정 리스트

### 가정 1: AI-Powered PKM 서브시장 비중
- **가정:** 전체 PKM 시장($7.71B) 중 AI-Powered PKM이 40% 차지
- **근거:** PHASE 1 분석, AI 트렌드 분석 결과
- **리스크:** 실제 비중이 30% 이하일 경우 TAM $2.3B로 축소
- **완화 전략:** AI 기능 강화로 서브시장 비중 확대

### 가정 2: 한국 시장 규모
- **가정:** 한국 PKM 시장이 세계 시장의 4.2% ($125M / $3B)
- **근거:** 한국 인구 비율(0.64%) 대비 지식 노동자 비율 높음 (40% vs 30%)
- **리스크:** 실제 한국 시장이 $100M 이하일 경우
- **완화 전략:** 한국어 최적화, 로컬 콘텐츠 지원으로 시장 확대

### 가정 3: 프리미엄 전환율
- **가정:** PKM 도구 사용자의 20%가 프리미엄 플랜 사용
- **근거:** 경쟁사 분석 (Notion 15-20%, Readwise 20-25%)
- **리스크:** 실제 전환율이 10% 이하일 경우 ARPU 감소
- **완화 전략:** 무료 플랜 기능 제한, 프리미엄 가치 명확화

### 가정 4: 시장 성장률
- **가정:** PKM 시장이 연평균 15-20% 성장
- **근거:** ResearchAndMarkets CAGR 47.2% (2024-2029), 보수적 추정
- **리스크:** 성장률이 10% 이하로 둔화될 경우
- **완화 전략:** AI 기능 강화로 시장 성장 주도
