### 2. 🔒 Problem

<aside>
<img src="Tip%201.svg" alt="Tip%201.svg" width="40px" /> 제품이 해결하고자 하는 **고객의 구체적인 문제**를 정의하세요.
</aside>

- **수집의 오류 (Collector's Fallacy)**
    - 80% 이상의 사용자가 정보를 저장만 하고 다시 보지 않음.
    - 정작 필요할 때 정보를 찾지 못하는 좌절감.
- **정리의 숙제화 (Manual Overhead)**
    - 폴더 분류, 태깅 등 수동 정리에 매일 10-30분 소모.
    - 생산성 도구가 오히려 또 다른 '업무'가 되는 피로감.
- **링크 소멸 및 정보 파편화 (Link Rot)**
    - 저장한 원본 페이지가 사라지거나 링크가 깨짐.
    - 여러 툴에 정보가 흩어져 맥락이 연결되지 않음.
- **자아의 상실 (Loss of Self)**
    - 정보 홍수 속에서 '나'의 관점과 감정이 거세된 차가운 데이터만 남음.

### Existing Alternatives

<aside>
<img src="Tip%202.svg" alt="Tip%202.svg" width="40px" /> 현재 이 문제를 해결하기 위해 고객이 사용하고 있는 **기존 대안/경쟁사**를 나열하세요.
</aside>

- **Notion / Evernote:** 범용 노트 앱이나 수동 정리가 필수적이며 정서적 가치가 부족함.
- **Obsidian / Logseq:** 강력한 연결을 제공하지만 학습 곡선이 높고 모바일 캡처가 불편함.
- **Readwise Reader:** 클리핑은 우수하나 로컬(한국어/네이버 등) 대응이 부족하고 의미적 재발견에 한계.
- **브라우저 북마크:** 가장 흔한 대안이나 '잊혀지는 정보의 무덤'이 됨.

### 4. 🔑 Solution

<aside>
<img src="Tip%203.svg" alt="Tip%203.svg" width="40px" /> 고객이 제품을 통해 경험하게 될 **해결책**을 설명하세요.
</aside>

- **영구 박제 (Immutable Archive):** WACZ 기술로 원본 증발 걱정 없는 완전한 보존.
- **제로 프릭션 자동 연결 (AI Auto-Linking):** 태그 없이 AI가 맥락을 분석해 지식 성좌 구성.
- **자아 회복 루틴 (The Atelier):** 밤 9시, 오늘 모은 조각들로 나를 기록하는 일기 시스템.
- **자연스러운 망각 (Natural Forgetting):** 인간 뇌를 모방하여 불필요한 정보는 점진적 희미화 (Phase 1.5).
- **감성 검색 (Resonant Search):** 키워드가 아닌 "그날의 기분"과 맥락으로 지식 재발견 (Phase 2).

### 7. 📊 Key Metrics

<aside>
<img src="Tip%204.svg" alt="Tip%204.svg" width="40px" /> 비즈니스 성장을 측정할 수 있는 **핵심 지표**를 정의하세요.
</aside>

- **Capture Rate:** 일일 평균 클리핑 횟수 (목표: 5+ clips/day)
- **Journal Completion:** 밤 9시 루틴 일기 완성률 (목표: 60%+)
- **Reconnection Rate:** 과거 클립 재방문 및 일기 인용률 (목표: 40%+)
- **30-Day Retention:** 일기 습관 형성 사용자 지속률 (목표: 60%+)
- **North Star Metric:** 사용자가 과거 기록을 통해 '나'를 재발견한 순간의 횟수.

### 5**.** **🎁 Unique Value Proposition**

<aside>
<img src="Tip%205.svg" alt="Tip%205.svg" width="40px" /> 제품만의 **독보적인 가치**와 기존 대안과의 **결정적 차이점**을 기술하세요.
</aside>

- **"당신의 지혜가 쌓이고, 당신의 영혼이 숨 쉬는 서재."**

- 인간의 망각과 기억 메커니즘을 시스템적으로 구현한 유일한 PKM.
