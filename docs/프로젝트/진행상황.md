## 🎯 선정된 시장: PKM (Personal Knowledge Management)

### 시장 요약

| **항목** | **내용** |
|---------|---------|
| **시장명** | PKM (Personal Knowledge Management) |
| **시장 규모** | $7.71B (2025년 예상) |
| **성장률** | CAGR 47.2% (2024-2029) |
| **핵심 페인 포인트** | 수집의 오류, 도구 피로감, 정서적 단절 |

### 핵심 페인 포인트 상세

#### 1. 수집의 오류 (Collector's Fallacy)
- **현상:** 저장하는 행위 자체에서 도파민을 느끼지만 정작 활용하지 않음
- **영향:** 저장만 하고 다시 보지 않음, 정작 필요할 때 찾지 못함

#### 2. 도구 피로감 (Tool Fatigue)
- **현상:** 시스템 구축과 최적화(플러그인, 설정)에 너무 많은 시간 소모
- **영향:** 본질적인 사고를 방해받음

#### 3. 정서적 단절 (Lack of Emotional Resonance)
- **현상:** 기록이 '차가운 데이터'로만 남아 있음
- **영향:** 다시 들여다보고 싶은 '애착'이 생기지 않음

### 주요 경쟁사

| 경쟁사 | 강점 | 약점 |
|---------|------|------|
| **Obsidian** | 강력한 플러그인, 보안 | 높은 학습 곡선, 감성적 경험 부재 |
| **Notion** | 뛰어난 협업, 범용성 | 프라이버시 불안, 정보 파편화 |
| **Logseq** | 저널링 중심 연결 | 성능 저하, 모바일 불안정성 |

## 🛠 기술 스택 요약

### 3대 핵심 엔진

#### 1. 영구 박제 엔진 (Permanent Archive Engine)
- **MVP:** SingleFile CLI + S3 저장
- **확장:** Playwright + WACZ (Web Archive Collection Zipped)
- **비용:** 캡처당 ~$0.01-0.05
- **특징:** 원본 URL이 사라져도 사진관 내 데이터 영구 접근 가능

#### 2. 감성 검색 엔진 (Emotional Search Engine)
- **모델:** Plutchik 8대 감정 + VAD(Valence-Arousal-Dominance)
- **프라이버시:** Local LLM (Ollama) 우선 처리
- **검색:** 벡터 유사도 + 감성 메타데이터 필터링 하이브리드
- **KPI:** 감성 분석 정확도 F1 Score 0.75+, 응답 속도 500ms 이내

#### 3. 시맨틱 그래프 엔진 (Semantic Graph Engine)
- **프레임워크:** LlamaIndex (PropertyGraphIndex) + Neo4j
- **최적화:** LazyGraphRAG 패턴 (운영 비용 70-90% 절감)
- **검색:** Vector 유사도 + Graph 위상 구조 + Keyword 하이브리드
- **시각화:** D3.js (Constellation View)

- [ ] 초기 필터링: 다음 기준으로 3개로 축소
  - [ ] 문제 발생 빈도가 높은가?
  - [ ] 현재 해결책이 불완전한가?
  - [ ] 데이터로 측정 가능한가?

### Step 2: 1차 데이터 수집
- [ ] **시장 규모:** 통계청, 산업 리포트 수집
- [ ] **고객 행동:** 설문 데이터, 리뷰 분석
- [ ] **경쟁사 현황:** 기업 공시, 뉴스 수집
- [ ] **기술 트렌드:** 특허, 논문, 기술 블로그 분석

### Step 3: 문제 가설 구체화
- [ ] 현재 상태 (As-Is) 분석
- [ ] 근본 원인 (Root Cause) 분석
- [ ] 기존 해결 시도 분석
- [ ] 검증 가능한 지표 설정

### Step 4: 최종 시장 선정
- [ ] 평가 매트릭스 작성 (3개 후보 점수화, 각 10점 만점)
- [ ] AI 의사결정 지원
- [ ] 최종 선택: 가장 높은 점수의 시장 1개 확정 + 선정 이유 문서화
